이번 작업은 UPRE Core / Schema / Fixture / PHASE 0B 결과를 변경하지 않는다.

## receiver.ps1 요구사항

Windows PowerShell에서 실행 가능한 최소 Receiver를 구현한다.

한 번 실행 시 정확히 하나의 미처리 DIR만 처리한다.

순서:

1. 현재 경로가 정확히 `D:\projects\UPRE-V0.10`인지 확인한다.
2. `git status`가 예상치 못한 DIRTY 상태이면 자동수정하지 말고 `HUMAN_REQUIRED`로 종료한다.
3. `git fetch` 후 fast-forward 가능한 경우에만 `git pull --ff-only` 한다.
4. `.master/inbox/DIR-*.md` 중 아직 처리되지 않은 가장 낮은 COMMAND_ID 하나를 선택한다.
5. `.master/state/executor.json`에서 중복 실행 여부를 확인한다.
6. PROJECT가 `UPRE-V0.10`인지 검사한다.
7. 현재 명령의 SCOPE와 STOP 조건을 읽는다.
8. 안전 Gate를 통과한 경우에만 Codex 실행을 준비한다.
9. 실행결과를 `.master/responses/RES-XXXX.md`로 작성한다.
10. 성공적으로 결과가 기록된 경우 원본 DIR을 `.master/processed/`로 이동한다.
11. state를 갱신한다.
12. Commit 후 Push한다.
13. 종료한다.
