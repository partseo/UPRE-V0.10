## MASTER CORRECTION GATES

### G03 — Relation Truth Classification

Entity와 Relation 모두 다음 Truth Classification을 명시적으로 지원해야 한다.

- OBSERVED
- DERIVED
- INFERRED
- USER_VERIFIED
- CONFLICT

Relation이 INFERRED이면 Evidence와 명시적 AI inference provenance가 필요하다.

Relation이 USER_VERIFIED이면 USER provenance가 필요하다.

Relation이 CONFLICT이면 서로 구분 가능한 다중 Evidence가 필요하다.

이 규칙은 Schema와 Semantic Validator 양쪽에서 실제로 검증되어야 한다.

### G04 — Real Original / Working / Generated Separation

`immutable: true` 플래그만으로 Original 불변성을 PASS 처리하지 않는다.

Working Model의 Entity 또는 Relation 값이 변경되어도 Original Model이 참조하는 역사적 값이 변하지 않아야 한다.

Generated Model 변경도 Working / Original에 역전파되지 않아야 한다.

최소 Versioning 또는 revision-owned value 구조로 실제 값 분리를 보장하되 전체 모델 재설계는 하지 않는다.

반드시 실행 가능한 테스트로 다음을 증명한다.

1. Original에서 Entity 이름 V1 존재
2. Working에서 동일 의미 Entity 이름 V2로 변경
3. Original 조회 결과는 V1 유지
4. Generated에서 V3로 변경
5. Working은 V2 유지
6. Original은 V1 유지

Relation 변경에도 같은 역사적 분리 원리가 적용되는지 최소 1개 검증한다.

### G05 / G06 — External Tool Isolation Fail-Closed

Core Schema 파일에 특정 문자열이 없다는 검사만으로 PASS 처리하지 않는다.

Program Model Instance에 Viewer / Editor 전용 상태가 침투하면 실제 Schema Validation 또는 Semantic Validation이 거부해야 한다.

최소 Negative Fixture:

- React Flow 전용 position / viewport 류 필드 침투
- Archify renderer / layout metadata 류 필드 침투

둘 다 FAIL해야 한다.

JSON Schema Draft 2020-12의 object closure를 올바르게 사용한다. `allOf`와 `additionalProperties` 조합 때문에 합법 필드까지 잘못 막히지 않도록 검증하고, 필요한 경우 `unevaluatedProperties`를 사용한다.

Archify IR과 React Flow node/edge/editor state는 계속 Adapter / Projection 소유로 유지한다.

### G10 — Real JSON Schema Validation + Semantic Validation

검증을 명확히 두 계층으로 분리한다.

LAYER A — 실제 JSON Schema Draft 2020-12 validation

LAYER B — UPRE cross-reference / provenance / immutability 등 semantic validation

Positive Fixture는 두 계층 모두 PASS해야 한다.

Negative Fixture는 의도된 계층에서 반드시 FAIL해야 한다.

일반 JSON Schema Engine을 dev/test 전용으로 사용할 수 있다. 사용 시 버전을 exact pin하고 제품 Runtime dependency와 분리한다.

Validator 자체가 Schema 일부를 수동으로 흉내 내는 것만으로 G10 PASS 처리하지 않는다.

실제 실행 명령, Exit Code, Test Count, Passed, Failed를 receipt에 기록한다.
